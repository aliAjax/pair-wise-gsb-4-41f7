# 声线练习室（Pronunciation Lab）

纯前端的英语发音练习应用。支持**评分口径版本管理**与**已掌握句子的复评流程**。

## 功能口径

### 评分口径版本
- 登记新口径：填写名称与「听清度 / 重音 / 流利度」三项权重，权重和必须为 100，否则不能保存。
- 同一时间只允许存在一个草稿口径；已有草稿时不能再登记新草稿。
- 启用草稿后，旧口径归档；**启用只影响此后的练习**，每条历史成绩永久绑定提交时的口径与句子版本。
- 启用新口径时，所有「已掌握」句子转入「待复评」。

### 掌握复评
- 待复评句子须在**当前启用口径**下、对**当前句子版本**连续两次成绩达到 85 分，才恢复为已掌握。
- 期间任意一次低于 85 分，连续计数清零。
- 复评期间修改句子会先生成新版本，复评在新版本上重新计数；旧版本与旧成绩保留。

### 重开一致性
- 每次加载与状态变更都会交叉校验：练习记录 × 口径版本 × 待复评队列。
- 发现冲突时在页面顶部列出：句子、分值与违反的规则（如成绩与口径权重不符、复评进度与记录不一致等）。

## 分层结构（不引入新依赖）

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/lab/types.ts`、`src/lab/seed.ts` | 领域类型、初始数据 |
| 判定 | `src/lab/rules.ts` | 口径登记/启用、加权评分、复评计数、一致性校验（纯函数） |
| 存储 | `src/lab/storage.ts` | localStorage 读写、旧版句子数据迁移（唯一接触浏览器存储） |
| 页面 | `src/ui/*`、`src/App.tsx` | React 组件与状态胶水（`useLab.ts`） |
